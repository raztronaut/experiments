## 1. Style baseline (per zone)

Established by sampling 2–3 “clean” files per zone. Use this to judge “inconsistent” elsewhere.

### lib

- **Sampled:** `src/lib/env.ts`, `src/lib/experiments.ts`, `src/lib/toolkit/scroll.ts`
- **Comment density:** Sparse. env.ts: none. experiments.ts: short section comments (e.g. `// React.cache() deduplicates...`), JSDoc on public APIs. scroll.ts: one JSDoc block for `createUnifiedScroll`, no inline clutter.
- **try/catch:** Only where I/O or external failure is expected (e.g. experiments.ts: FS read, per-dir config read; articles.ts: experiment.json optional). Catches log or return fallback, not empty.
- **any / as unknown as:** experiments.ts uses `return obj as unknown as Experiment` after validation (narrowing from Record). scroll.ts uses `(options as UnifiedScrollOptions)` for overload discrimination. No bare `any`.
- **Nesting / early returns:** Early returns in validators; moderate nesting in async maps; no deeply nested conditionals.

### app

- **Sampled:** `src/app/(main)/layout.tsx`, `src/app/experiments/(luma-morphing)/luma-morphing/page.tsx`
- **Comment density:** layout: minimal (metadata/config). page: none (thin wrapper).
- **try/catch:** layout has inline script with `try { ... } catch (e) {}` for feature detection (touch, cursor hidden). Empty catch is in string, not application code.
- **any / as unknown as:** None in sampled app files.
- **Nesting:** Shallow; layout is declarative JSX.

### components/ui

- **Sampled:** `src/components/ui/ExperimentNav.tsx`, `src/components/ui/tooltip.tsx`
- **Comment density:** ExperimentNav: one block comment for iframe-hide script. tooltip: none.
- **try/catch:** ExperimentNav: inline script only (`try{...}catch(e){}` in dangerouslySetInnerHTML). No app-level try/catch.
- **any / as unknown as:** None in tooltip. (ConsoleEasterEgg has `(window as any)` — see inventory.)
- **Nesting:** Flat; early returns for conditional render.

### components/experiments

- **Sampled:** luma-morphing (LumaMorphing.tsx, data.ts), cursor-depth-explorer (CursorDepthExplorer.tsx)
- **Comment density:** data.ts: JSDoc on exported helpers; short inline where non-obvious. LumaMorphing: almost none. CursorDepthExplorer: section comments in shader and useFrame (`// --- Reveal Animation ---`, `// Interactive Logic`), inline for math/behavior.
- **try/catch:** None in sampled experiment components.
- **any / as unknown as:** CursorDepthExplorer has `scale as any` on mesh (Three.js scale type). VisualiserLogic has explicit “as any” for drawImage with comment.
- **Nesting:** LumaMorphing: shallow. CursorDepthExplorer: deeper in useFrame (if/else chains, refs); could be simplified with early returns or extracted helpers.

**Baseline summary:** Terse comments; try/catch only for I/O or optional features; casts rare and either validated-before-cast or documented; prefer early returns over deep nesting.

### Report summary (per category)

- **Comments:** Baseline is terse; TypographyDebugPanel and CursorDepthExplorer use section/shader comments intentionally. No broad slop; flag only files that add obvious-inline comments at high density.
- **Defensive try/catch:** All current try/catch are I/O, fetch, optional config, or intentional empty catch (inline scripts, releasePointerCapture). Keep; document optional experiment.json in articles.ts and empty catches in layout/ExperimentNav/VisualiserLogic.
- **Type casts:** Two medium-priority remediations (ConsoleEasterEgg window, CursorDepthExplorer scale); several low/document-only (experiments.ts, InteractiveWidget, registry, TypographyDebugPanel, VisualiserLogic comment). Do first: ConsoleEasterEgg and CursorDepthExplorer in Tier 1/2.

- **Inconsistency:** Spot-check done via baseline; no major outliers beyond the cast and length findings above.


Or manually:

- `grep -rn 'as any\|as unknown as\|: any' src/` (experiments repo only)

## 2024-10-24 - Accessibility and keyboard interactions in the chat input
**Learning:** Found multiple instances where buttons (like attach file and voice input in `SendButton.tsx`, and the submit button in `AnimatedSendButton.tsx`) had `tabIndex={-1}`, which breaks keyboard accessibility. They were completely skipped by screen readers and keyboard users. Also, pressing `Enter` to send wasn't supported.
**Action:** Remove `tabIndex={-1}` from semantic `button` tags to ensure natural keyboard flow. Add `focus-visible` states to display focus rings without causing visual noise for mouse users. When implementing an input that looks like a chat bar, ensure `Enter` acts as a submit if a form element isn't used.

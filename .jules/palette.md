## 2025-03-20 - Explicit button types in Error Boundaries
**Learning:** React Error Boundaries (like `ExperimentErrorBoundary`) can unexpectedly submit forms if their fallback UI includes `<button>` elements without explicit types (which default to `type="submit"` in HTML), leading to jarring page reloads or side effects when an error occurs inside a form context.
**Action:** Always add `type="button"` to `<button>` elements in fallback UIs and generic components unless they are explicitly intended to submit a form.
## 2026-06-04 - Toggle Buttons Accessibility
**Learning:** Custom UI toggle buttons (such as the list/grid layout switch) need an explicit `aria-pressed` state to communicate their active state dynamically to screen readers. Furthermore, adding explicit `focus-visible` styles with `outline-hidden ring-1 ring-ring` is crucial for keyboard users to visually identify the focused control.
**Action:** When implementing custom toggle controls using generic HTML buttons or `Lucide` icons wrapped in buttons, always provide an `aria-pressed={isActive}` property, a defined `type="button"`, and include `focus-visible:outline-hidden focus-visible:ring-1 focus-visible:ring-ring` in the className for complete accessibility.

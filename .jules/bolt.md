## 2024-05-14 - React Cache Scope Learning
**Learning:** React's `cache` function is scoped to a **single server request** (or a single page render during static generation), not shared globally across requests. While caching an O(1) map generation prevents N^2 scans within a single request (e.g. mapping over articles), it does not share that map across independent requests. In Next.js SSG build context where articles might be fetched repeatedly in one pass, there might be a benefit, but for individual requests, allocating a map is slower and uses more memory than a simple findIndex.
**Action:** Be careful about creating "optimizations" that do expensive initial work (like building maps) if the cache is scoped per-request and the lookup is only needed once or twice per request.
